## 四、实际回答仍需人工复核的情形

1. 已签核17项的**示例之外**的新型不完整回答；是否属于可指认、非实质遗漏仍有争议。
2. 回答出现错误历史事实、对象归属或主体错配、时间和数量等关键限定语实质失真。
3. 同时包含正确与错误陈述，或存在与教材冲突的推断。
4. 模型只出现关键词但没有表达正确关系、因果、比较或历史结论。
5. 20项满分/0分的回答出现边界不清的同义表达时，先人工核实，不擅自增设50%档。
6. 任何其他未正式签核的A/B/D规则所触发的待人工复核不受本轮C类签核解除。
